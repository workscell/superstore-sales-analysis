# Superstore Sales Analysis

## Project Overview

This project is an end-to-end sales analysis using the Superstore dataset. The purpose of this project is to analyze sales performance, profitability, customer orders, and product performance to generate business insights through data analysis and visualization.

## Tools & Technologies

- **Microsoft Excel** – Data exploration and analysis
- **PostgreSQL** – Data querying and analysis using SQL
- **Microsoft Power BI** – Data visualization and interactive dashboard

## Dataset

This project uses the Superstore Sales Dataset from Kaggle.

- **Source:** [Superstore Sales Dataset – Kaggle](https://www.kaggle.com/datasets/himanshuuike/superstore-sales-dataset)
- **License:** CC0 1.0 Universal (as listed on the dataset page)
- **Format:** CSV

The raw dataset is not included in this repository. Please download it from the original source before reproducing the analysis.

## Project Workflow

1. **Excel Analysis**
   - Explore and analyze the dataset.
   - Perform calculations and summarize sales performance.

2. **SQL Analysis**
   - Query and analyze sales data using PostgreSQL.
   - Use SQL to explore sales, profit, products, and regional performance.

3. **Power BI Dashboard**
   - Prepare and transform data using Power Query.
   - Create measures using DAX.
   - Build an interactive dashboard to monitor sales performance.
